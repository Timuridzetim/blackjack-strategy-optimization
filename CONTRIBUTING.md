# Development workflow

This repository is currently in the planning stage. Implementation has not started.

1. Choose an open GitHub Issue before starting a change.
2. Create a descriptive feature branch from `main` (for example, `feature/markov-model`).
3. Keep model assumptions explicit and add tests for mathematical or behavioral changes.
4. Submit a pull request referencing the related Issue, explaining what changed, how it was checked, and any limitations.
5. Do not include unverified simulation results, personal identifiers, or the original IA PDF without review.

Initial scope is a simplified blackjack model; more realistic gameplay rules belong to later, separately documented extensions.
